# Step Builder onboarding guide

The getting-started guide for **Step Builder**, for whoever has been handed a recorded procedure
and asked to turn it into steps a technician can follow on a RealWear headset.

**Read it here: https://analogds.github.io/step-builder-onboarding/**

<img width="1000" height="400" alt="image" src="https://github.com/user-attachments/assets/cc2e7e2b-8969-4f2f-8825-7fd8590b9dfc" />

One self-contained HTML file — every screenshot is embedded, so it renders with no network and
prints to PDF from the browser with `Cmd-P`.

## This repo is generated

`index.html` is built output. **Do not edit it here.** It is written from
`docs/onboarding.src.html` in the private `analogds/Step-Builder` repo and pushed by
`docs/onboarding-kit/publish.sh`; anything changed here is overwritten on the next publish.

Nothing else belongs in this repo. It exists to hold one public document, and deliberately
contains no application source and no configuration.

## Something in the guide is wrong

The guide is written against the live application, and the application keeps moving. If a screen
in front of you does not match a picture here, trust the screen — then open an issue on
`analogds/Step-Builder` so the guide gets refreshed.
